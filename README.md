# Muhammad Faisal Hameed: Interactive 3D Portfolio

A game-style 3D portfolio built with Three.js and Vite (work in progress). See `PLAN.md` for the plan and `DEVLOG.md` for decisions and measurements.

## Run locally
```
npm install
npm run dev
```
Copy `.env.example` to `.env.local` and fill in your own keys (never commit it).
